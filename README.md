## FAQ

### What is XCutors?

XCutors is a curated Windows desktop collection that bundles several popular Roblox script executors—Volt, Synapse Z, Potassium, Wave—along with a universal loader (xcutorsLoader) so you can manage them all from a single interface.

### Is XCutors free to use?

Yes. The loader and the open-source components of the package are completely free. Some bundled executors may have their own premium tiers; please check each executor's official page for details.

### Which executors are included?

The package ships with Volt, Synapse Z, Potassium, Wave, and xcutorsLoader, which serves as the universal loader and manager for all of them.

### What operating systems are supported?

XCutors is designed exclusively for Windows. It has been tested on Windows 10 (version 1903 and later) and Windows 11.

### How do I update the executors?

Open xcutorsLoader, navigate to the executor you want to update, and click 'Install / Update'. The loader will fetch the latest version automatically.

### Can I load my own Lua scripts?

Absolutely. Every included executor has an open script editor. You can paste Lua code directly, load .lua files from disk, or import scripts from URLs.

### Windows Defender or my anticomponent flags the program. Is it safe?

Anticomponent false positives are common with script executors because they inject code into other processes. Always download XCutors from the official GitHub Releases page and verify the file hash. If you are uncomfortable, you may whitelist the folder manually.

### Where can I get help or report a bug?

Open an issue on the GitHub repository or join the community Discord server linked in the README. The community and maintainers are active and happy to help.

### Do I need to run the executor as administrator?

Yes. Script executors need elevated privileges to attach to the Roblox process. Always launch xcutorsLoader.exe or the individual executor with 'Run as administrator'.
